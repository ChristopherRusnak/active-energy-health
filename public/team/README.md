# Team headshots

Drop headshot files straight into this folder using the exact names below.
They are picked up automatically the next time the site builds — no code change needed.

- **Format:** .jpg, .jpeg, .png, .webp or .avif (extension does not matter, the name does)
- **Crop:** portrait, 4:5 ratio (e.g. 800 x 1000). Anything else is centre-cropped to fit.
- Anyone without a file here shows a neutral "Photo coming" tile, so partial sets look fine.
