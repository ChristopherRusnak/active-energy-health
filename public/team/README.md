# Team headshots

**Drop the files in here exactly as they come out of Google Drive.** No renaming needed —
`Michael_07_13_2026.png` is matched to Michael McFadden automatically. They appear the next
time the site builds; no code change required.

- **Format:** .jpg, .jpeg, .png, .webp or .avif
- **Crop:** portrait, 4:5 (e.g. 800 x 1000). Anything else is centre-cropped to fit.
- Anyone without a file shows a neutral "Photo coming" tile, so partial sets look fine.

## How matching works

1. Exact slug — `andrea-clinton.jpg`
2. Leading first name — `Andrea_07_13_2026.png` → Andrea Clinton

A first name shared by two people on the roster is treated as ambiguous and matched to
neither, rather than guessed at.
